# Product Training Sandbox

This repository is created to practice the basic GitHub workflow used for managing product requirements, documentation, branches, issues, and pull requests.

## Project Goals

- Understand how to create and manage a GitHub repository.
- Learn how to write a clear GitHub Issue from a product requirement.
- Practice writing documentation using Markdown.
- Understand how branches are used to make changes safely.
- Learn how Pull Requests help in reviewing and approving changes before merging.

## Success Criteria

- A repository named `product-training-sandbox` is created.
- A GitHub Issue is created using the user story format.
- The README file clearly explains the project goals and success criteria.
- A new branch is created for making a README update.
- A Pull Request is opened and linked to the issue using `Closes #1`.
- - The workflow demonstrates how a Product Associate can track and review a feature lifecycle.
